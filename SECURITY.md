# Security policy

Please do not disclose an unpatched vulnerability in a public issue.

Use GitHub **Private vulnerability reporting** for this repository and include:

- affected release and DSM matrix;
- concise reproduction steps;
- expected and observed behavior;
- security impact;
- relevant sanitized logs with secrets and private host identifiers removed.

General compatibility questions and non-sensitive defects may use public GitHub
issues. Never publish credentials, NAS addresses, notification recipients,
backups or unredacted DSM logs.
