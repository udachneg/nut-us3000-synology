Setup

This native package supports one USB-connected UGREEN US3000 with identity 2b89:ffff, serial DC600. It uses NUT 2.8.5 and no runtime container.

In Control Panel > Hardware & Power > UPS, select Synology UPS Server, enter 10.255.255.1, and set the safe-mode delay to the recommended 5 minutes. The host-local DSM endpoint is 10.255.255.1:3493.

Verification

The package description uses ◆ between sections and · between items. Start, recovery checks and stop update its state and observation time in UTC. Reloading the DSM page may be necessary to display the new text.

Communication confirmed applies only to the displayed observation time. If it is older than 10 minutes, the state is unconfirmed. Waiting after boot, UPS unavailable, communication problem, check failed and package stopped do not indicate working protection. A description update failure does not stop the UPS service, so always check the age of the text.

In the status block: 🟢 UPS communication confirmed; 🔴 communication problem or UPS unavailable; 🟡 waiting, check pending or check failed; ⚪ package stopped. The color refers to the displayed check time: if older than 10 minutes, the state is unconfirmed regardless of the circle.

DSM setup and firewall are checked independently: 🟢 settings checked; 🔴 settings differ from the selected configuration; 🟡 could not verify. DSM checks saved enable, mode, server and delay fields. A delay other than the selected 5 minutes is not inherently unsafe.

Firewall green requires an enabled persistent DSM profile with the first enabled global TCP 3493 deny and the recognized effective rule order. A temporary block is not enough. Loopback and established connections retain normal exceptions; no external connection test is performed.

Only the DSM format observed on the target NAS is recognized. Missing system jq, unknown formats or timeouts produce yellow without affecting UPS operation. Settings are never changed automatically. Settings or communication checks do not prove battery runtime or a complete DSM power-failure scenario.

The 5-minute delay is a DSM setting, not a guarantee of battery runtime at any load. Do not use the value 65535 seconds to estimate runtime.

Package Center: Running means that the package controller is active. It does not by itself mean that the UPS is connected. Check the actual connection, charge and power state in the DSM UPS UI. Standard DSM notifications report UPS-server loss and restoration.

Control Panel > Security > Firewall: add a DENY rule for TCP 3493, all sources and all interfaces, above allow rules in the active profile. Apply the profile. Do not open this port to the network. This persistent DSM rule is configured manually; the temporary package guard does not replace it.

Start and stop

Use Package Center to start or stop NUT US3000. Start performs one immediate USB attempt and keeps the controller active for safe retries. Stop ends the controller first, then NUT, and restores the exact USB interface.

USB recovery

Starting with 0017, the package grants its group access to the single exact UPS 2b89:ffff / DC600. No manual udev rule is required. Stop and uninstall revoke that grant, leaving root:root mode 0600 until the next start or USB reconnect. Other USB devices are not modified.

If USB is unavailable during boot, the first recovery attempt waits until system uptime reaches 10 minutes; later checks run every 5 minutes. Reconnect only the USB data cable. Keep mains power and the protected load connected.

DSM update

This build is validated only on Xpenology/Arc presenting SA6400 with DSM 7.2.2-72806 on epyc7002. Other DSM builds and official Synology models are untested. After every DSM update, verify Package Center status, USB identity, both local endpoints, the DSM UPS connection and the non-local firewall denial before relying on protection.

Uninstall

The uninstall wizard can keep package data for reinstall or delete the package-owned home, configuration and state. It does not remove DSM UPS settings, the DSM-managed firewall rule or external host integration. Review those host settings manually after uninstall.

Limitations

Only the exact UGREEN US3000 USB identity above is supported. The package does not estimate runtime from the device value 65535, control UPS load power, or replace DSM shutdown and notification policy.

If local help is unavailable after stopping the package, use the GitHub instructions.
